# Console brand fonts

Inter (400, 500, 600) and JetBrains Mono (400) reuse PhiloCyber's approved font
assets. They are self-hosted through `next/font/local`, including in embedded
builds. The UI uses Inter for controls and body text; JetBrains Mono is reserved
for code, identifiers and measurements.

Both families use the SIL Open Font License 1.1. The original notices are retained
in `OFL-Inter.txt` and `OFL-JetBrainsMono.txt`.

Upstream: [Inter](https://github.com/rsms/inter),
[JetBrains Mono](https://github.com/JetBrains/JetBrainsMono).
